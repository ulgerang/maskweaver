# Weave Bounded Loop Initiative

Status: `draft`

Goal:

- Add a Ralph-like bounded loop to `weave` without importing external product concepts into the public UX.
- Keep `worker`, `verifier`, and `controller` separated.
- Make retries change-scoped, logged, and budgeted.
- Make each loop run addressable by a human-readable `loopId`.
